# 智能车手机控制台

在线地址：<https://epochhit.github.io/smart-car-controller/>

面向 STM32F103 智能车的手机巡线调试网页。目前使用 JDY-31-SPP；在 Android 系统蓝牙中完成配对后，使用 Chrome 137 或更高版本打开网页并连接。

## 页面说明

- **巡线**：主功能。停车时也持续读取四路原始值；标定后可启动 PID 巡线，并随时开关避障。
- **遥控**：附加测试工具，只保留 XY 摇杆、基础运动和 90° 标定。
- **调参**：主要调整巡线 PID、基础速度、识别阈值和一次避障参数。
- **日志**：遥控与巡线分别导出；巡线日志包含失败原因、峰值误差及当时四路数据。

## 少数参数说明

- **原始 ADC**：未标定时最可信的数据，可以直接复制后用于初步设参。
- **传感器百分比**：完成范围标定后才显示，计算方式为 `(当前值 - 最小值) / (最大值 - 最小值)`。
- **巡线 PID**：根据赛道方向误差实时产生左右差速，不是左右轮匀速标定。
- **峰值误差**：由小车在 20 ms 控制周期内记录，包含发生时间、赛道状态、PID 输出和四路传感器现场。

必须烧录与网页协议匹配的最新 `car_main.hex`。
