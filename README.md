# 智能车手机控制台

在线地址：<https://epochhit.github.io/smart-car-controller/>

Android APP：<https://github.com/EpochHIT/smart-car-controller/releases/latest/download/smart-car-controller.apk>

面向 STM32F103 智能车的手机巡线调试工具。目前使用 JDY-31-SPP，UART 固定为 57600、8N1。连接后网页用 ASCII + CRLF 发送模式命令并等待小车确认；握手失败时会区分“RX=0 字节”和“收到数据但没有合法确认”。

页面顶部以 `月-日 时:分` 显示网页或 APP 的构建时间；连接小车后，蓝牙区域同时显示固件编译时间，便于确认网页和板载代码是否都是最新版。

APP 会列出系统中已经配对的经典蓝牙设备，支持按名称或 MAC 地址搜索，并记住上次连接。首次使用前仍需在 Android 系统蓝牙中完成配对。

连接成功后网页会等待串口稳定，再请求进入“巡线待机”；若首包丢失会自动重试三次。只有收到小车返回的真实模式确认才会开放启动按钮。点击“遥控”或“巡线”页签会直接切换小车模式，不需要再点第二个“进入模式”按钮。

## 页面说明

- **巡线**：主功能。停车时也持续读取四路原始值和前向距离；加载当前硬件的传感器档案后可启动 PID 巡线，并随时允许或禁止固定绕障动作。
- **遥控**：附加测试工具，只保留 XY 摇杆、基础运动和 90° 标定。
- **PID 参数**：打开页面自动读取；Kp/Kd/Ki 按实际小数显示，网页保存时自动换算成固件整数。
- **日志**：遥控与巡线分别导出；巡线日志包含失败原因、峰值误差及当时四路数据。

## 少数参数说明

- **原始 ADC**：最可信的硬件测量值，可以直接复制后用于重新拟合传感器档案。
- **传感器百分比**：每路独立计算 `(当前值 - 最小值) / (参考值 - 最小值)`；横线圈的参考值是车身居中的实测值，超过后夹到 100%，避免饱和值造成固定方向偏差。
- **横竖含义**：横/竖表示线圈在车上的方向。小车正向沿导线行驶时，左横与右横应明显；车身垂直横跨导线时，左竖与右竖应明显。
- **四路顺序**：左横 PA4、左竖 PA5、右横 PB1、右竖 PB0。
- **巡线 PID**：根据赛道方向误差实时产生左右差速，不是左右轮匀速标定。
- **十字识别**：左右竖线圈必须同时超过阈值，单个竖线圈冲高只表示车身偏向一侧，不判十字。
- **峰值误差**：由小车在 20 ms 控制周期内记录，包含发生时间、赛道状态、PID 输出和四路传感器现场。
- **超声波开关**：测距在巡线模式中始终运行；开关只决定遇到障碍时是否执行写死的右侧绕行动作。前置单传感器无法判断哪一侧更空。

必须烧录协议 16 的最新 `car_main.hex`；旧固件不会被网页当作已确认模式。
