# 智能车蓝牙网页控制器

这个网页通过 JDY 蓝牙模块的 `FFE0/FFE1` 服务控制 STM32F103C8T6 智能车，可发送循迹、倒车、停车、传感器开关、避障开关和调速命令，并显示距离与循迹数据。

## 一、电脑上预览

推荐使用 Chrome 或 Edge。

1. 打开命令提示符或 PowerShell。
2. 进入 `web-controller` 文件夹。
3. 如果电脑装有 Python，运行：

   ```text
   python -m http.server 8000
   ```

4. 浏览器打开 `http://localhost:8000`。
5. 点击“选择蓝牙设备”，在浏览器设备列表中选择 JDY 模块。

如果电脑没有蓝牙，只能预览界面，不能连接小车。

## 二、部署成苹果手机可打开的网址

苹果手机需要通过 HTTPS 地址打开网页。最简单的免费方式是 GitHub Pages：

1. 注册并登录 GitHub。
2. 新建一个公开仓库，例如 `smart-car-controller`。
3. 把本文件夹中的 `index.html`、`styles.css`、`app.js` 上传到仓库根目录。
4. 打开仓库的 `Settings` → `Pages`。
5. 在 `Build and deployment` 中选择 `Deploy from a branch`。
6. 分支选择 `main`，目录选择 `/ (root)`，然后保存。
7. 等待一两分钟，GitHub 会给出一个 `https://...github.io/...` 地址。

## 三、苹果手机连接小车

普通 Safari 不能直接使用这个网页的蓝牙功能。

1. 在 App Store 安装 **Bluefy – Web BLE Browser**。
2. 打开手机蓝牙，并给 Bluefy 蓝牙权限。
3. 在 Bluefy 中输入上一步得到的 HTTPS 网页地址。
4. 给 JDY 模块和小车上电，确保模块未被其他手机连接。
5. 点击网页中的“选择蓝牙设备”。
6. 在系统蓝牙窗口中选择 JDY 模块。
7. 页面显示“已连接”后即可控制。

不要先在 iPhone 系统“设置 → 蓝牙”中配对。BLE 模块应当由网页中的“选择蓝牙设备”按钮连接。

## 四、控制命令

| 网页功能 | 发送内容 |
| --- | --- |
| 开始循迹 | `F` |
| 倒车 | `B` |
| 紧急停车 | `S` |
| 接入传感器 | `T` |
| 关闭传感器 | `N` |
| 开启自动避障 | `O` |
| 关闭自动避障 | `X` |
| 10%～90%速度 | `1`～`9` |

小车开机默认开启自动避障。发送 `X` 后，HC-SR04 仍继续测距，OLED 和网页仍显示距离，但距离不会再让小车自动减速或停车。

## 五、常见问题

- 搜不到模块：检查模块供电、手机蓝牙权限，以及模块是否已连接另一台设备。
- 能连接但无数据显示：确认 STM32 TX/RX 与模块交叉连接、波特率为 9600，并在网页连接后等待 FFE1 通知。
- 按钮无反应：查看页面底部通信日志。出现 `TX` 表示网页已尝试发送；出现 `ERR` 时按错误提示检查。
- 页面提示不支持网页蓝牙：苹果手机必须使用 Bluefy；电脑使用最新版 Chrome 或 Edge。
- 连接后立即断开：先关闭其他蓝牙调试助手，再给 JDY 模块重新上电后连接。
