# 智能车蓝牙控制台

面向 STM32F103 智能车的 Web Bluetooth 控制界面，使用 JDY 模块的 `FFE0 / FFE1` 服务。网页协议已与当前 `car_main` 固件的换行文本命令对齐。

## 本版改动

- 蓝牙连接、蓝牙遥控、传感器台架分成三个独立状态；连接成功不会自动启动电机或传感器。
- `MODE REMOTE` 与 `MODE SENSOR` 互斥，切换模式由固件先停车再初始化对应外设。
- 保留原本的 `FORWARD` 闭环直线命令。
- 新增 `PWM <左> <右>` 开环命令，左右轮 0–100% 分开设置，用于直线基础 PWM 标定。
- XY 摇杆模块只保留界面与混合约定，本版不监听触摸、不发送摇杆指令。
- 所有网页命令自动补换行，符合固件按行接收的协议。
- 主动断开蓝牙前先发送 `STOP`；意外断线时会明确提示无法确认停车状态。

## 使用顺序

1. 用 Chrome、Edge 或 iPhone 上的 Bluefy 打开网页。
2. 选择 JDY 蓝牙设备。网页连接后先发送 `CHECK`，但仍保持待机。
3. 选择“蓝牙遥控”或“传感器台架”。
4. 遥控模式下可以发送方向命令、原本的闭环 `FORWARD`，或左右轮独立 PWM。
5. 调试结束先点“全局停车”，再断开蓝牙或切回待机。

## 命令协议

| 网页操作 | 发送内容 | 说明 |
| --- | --- | --- |
| 待机 | `MODE STANDBY` | 停车并退出当前模式 |
| 蓝牙遥控 | `MODE REMOTE` | 启用电机与编码器，进入后仍停车 |
| 传感器台架 | `MODE SENSOR` | 启动传感器测试，不驱动车轮 |
| 前进 / 后退 / 左转 / 右转 | `FORWARD` / `BACKWARD` / `LEFT` / `RIGHT` | 仅遥控模式可用 |
| 全局停车 | `STOP` | 保留当前模式，PWM 立即归零 |
| 闭环直线 | `FORWARD` | 使用目标 CPS、双轮 PI 和长期直线修正 |
| 独立 PWM | `PWM 30 32` | 左轮 30%、右轮 32%，绕过速度 PI |
| 编码器反馈 | `ENC` | 读取累计计数、CPS 与闭环直线修正 |
| 电机反馈 | `MOTOR` | 读取四路实际 PWM |
| 状态与参数 | `CHECK` | 读取模式和当前固件参数 |

独立 PWM 是一条调试路径，不替代 `FORWARD`。发送任意方向命令会重新进入闭环控制；发送 `STOP` 立即结束当前动作。

## XY 摇杆约定（未启用）

后续摇杆把 X 作为转向、Y 作为前进/后退，再混合为左右轮目标：

```text
left  = clamp(Y + X)
right = clamp(Y - X)
```

启用时还需要确定死区、发送频率和固件侧对应命令。本版没有加入隐藏开关或半成品发送逻辑。

## 本地预览

在仓库目录运行：

```text
python -m http.server 8000
```

然后打开 `http://localhost:8000`。`localhost` 可用于桌面浏览器的 Web Bluetooth；iPhone 远程打开页面时仍需要 HTTPS。

## 关于私有仓库与私有网页

仓库可以设为 private，但普通个人账号的 GitHub Pages 即使源仓库是 private，发布后网页仍对互联网公开。真正限制访问的私有 GitHub Pages 需要组织使用 GitHub Enterprise Cloud。因此本项目默认只创建私有代码仓库，不自动开启公开 Pages。

如果后续接受“代码私有、网址公开”，可从仓库根目录开启 GitHub Pages；如果网址本身也必须私有，需要 Enterprise Cloud 组织或带登录访问控制的其他 HTTPS 托管服务。
