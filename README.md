# 智能车手机控制台

在线地址：<https://epochhit.github.io/smart-car-controller/>

面向 STM32F103 智能车的手机调试网页。目前使用 JDY-31-SPP；在 Android 系统蓝牙中完成配对后，使用 Chrome 137 或更高版本打开网页并连接。

## 页面说明

- **遥控**：日常驾驶、XY 摇杆、90°转弯标定，以及折叠收纳的直行诊断数据。
- **传感**：查看超声波距离和建议方向，测试舵机角度与自动扫描。
- **调参**：调整速度闭环、走直线、90°转弯和传感器参数，并保存到小车。
- **日志**：记录运行数据和实验条件，导出 CSV 供后续分析。

## 少数参数说明

- **CPS**：编码器每秒计数，用作轮速目标；它不是直接发送给电机的 PWM。
- **摇杆最低 CPS**：摇杆离开死区后采用的最低有效轮速，避免指令过小导致电机不转或运行不稳定。
- **前馈 PWM / 最大 PWM**：闭环控制内部使用的基础输出和输出上限，不是独立的 PWM 遥控速度。
- **速度 Kp、Ki**：单轮速度 PI 参数；页面中的数值按标签所写的倍率保存，例如 `Kp ×10000` 显示 50 代表实际值 0.005。
- **直线 Kp / 死区 count / 最大修正 CPS**：分别控制左右轮累计偏差的修正强度、忽略的小误差范围和允许的最大修正量。
- **左/右 90° count**：完成左转或右转 90°时的编码器计数，需要分别实车标定。
- **暂存 / 保存**：暂存只把修改放入待保存区，不影响当前运行；保存后才会应用参数并写入小车 Flash，断电后仍保留。

必须烧录与网页协议匹配的最新 `car_main.hex`。
